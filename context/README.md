# Frontend Context

Эта папка хранит короткий контекст по фронтенду сайта школы фехтования Ferrum et Gloria.

Файлы:

- `project.md` - назначение фронтенда, стек, запуск и общие правила.
- `routes-and-pages.md` - страницы, маршруты, источники данных и интерактивные состояния.
- `design.md` - визуальный стиль и правила развития интерфейса.

Используй эти заметки перед правками в `src`, чтобы не перечитывать весь проект с нуля.
