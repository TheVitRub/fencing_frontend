# Frontend Project Context

## Назначение

Фронтенд - публичный сайт и админ-панель небольшой школы исторического фехтования Ferrum et Gloria. Сайт рассчитан на камерную аудиторию: примерно 20-30 учеников, 1 основатель, 3-4 инструктора и малое число внешних зрителей из других школ.

## Стек

- React 18.
- React Router 6.
- Vite 5.
- Axios.
- CSS без отдельного UI-фреймворка.

## Команды

```bash
npm run dev
npm run build
npm run preview
```

Vite настроен на порт `3000`. Если порт занят, Vite может выбрать следующий свободный порт.

## API

Клиент находится в `src/api/client.js`.

- Базовый путь API: `/api`.
- JWT берётся из `localStorage` по ключу `fc_token`.
- Прокси Vite:
  - `/api` -> `http://localhost:8080`
  - `/uploads` -> `http://localhost:8080`

Список методов API находится в `src/api/index.js`.

## Важные файлы

- `src/main.jsx` - точка входа React.
- `src/App.jsx` - роутинг и защищённый маршрут админки.
- `src/context/AuthContext.jsx` - состояние авторизации администратора.
- `src/hooks/useFetch.js` - общий hook для загрузки данных.
- `src/styles/global.css` - глобальная тема, переменные цвета, типографика.
- `src/components/common` - Navbar, Footer, PageSection, ImageGallery.
- `src/components/admin` - CRUD-компоненты и загрузчик изображений.

## Соглашения

- Для новых публичных страниц добавлять маршрут в `App.jsx`.
- Для новых запросов добавлять функцию в `src/api/index.js`.
- CSS страницы хранить рядом с JSX страницы.
- Сохранять текущий историко-пергаментный стиль: тёплый фон, золото, бордо, тонкие рамки, типографика с `Cormorant SC`, `Parisienne`, `EB Garamond`.
- Не превращать сайт в большую социальную сеть: интерфейс должен ощущаться как клубная хроника небольшой школы.
